# MathModel 开发版

[MathModel Desktop](https://github.com/jihe520/MathModelAgent)（数模 Agent / 数学建模 AI 助手）的本地开发版。

免登录、不扣积分、不限权益，不连接官方后台服务器，更新走本仓库，局域网协作也能直接用。

适配官方 **v0.0.23 win-x64**。

## 特性

- **免登录** —— 打开即用，界面显示「开发者 / 开发版」，不需要 MathModel 账号
- **不扣积分** —— 不再走云端计费，也不用充值、兑换
- **不限权益** —— 没有到期时间之类的门槛
- **不连后台** —— 不向 `mathmodel.top` 发送任何请求
- **自带模型** —— 用你自己在「设置 → 供应商」里填的 API Key，直连服务商
- **自动更新** —— 内置「检查更新」指向本仓库 Release，需要更新时发一个 Release 即可
- **局域网协作** —— 同一个 WiFi / 手机热点下，队友之间可以一起做同一道题

## 用法

### 安装

到 [Releases](https://github.com/06xxlin/MathModelAgent-dev/releases) 下载最新的
`MathModel-<版本>-开发版-Setup.exe`，双击安装即可。

单文件、离线、**不需要管理员权限**。装完桌面和开始菜单会有「MathModel 开发版」。

### 配置模型

右上角「设置 → 供应商」，填入自己的 API Key（Anthropic / DeepSeek / Kimi / 通义等）。
不填也能打开界面，但发消息会提示缺少认证信息。

### 局域网协作

左边栏「局域网协作」→ 选一个项目 → **开房** → 把 6 位数字口令发给队友 →
队友在同一个 WiFi 下打开「局域网协作」就能看到房间，输入口令加入 → 房主同意。

三台设备连同一个 WiFi（或同一个手机热点）即可，数据只在你们之间传输。

> 队友连不上时：让队友和房主确认连的是**同一个** WiFi、且没开「客户端隔离」；
> 房主机器再跑一次 `dev-tools\allow-lan-collab.ps1`（右键以管理员身份运行）放行防火墙。

### 更新

程序启动后会自动检查本仓库的 Release，发现新版本会后台下载，界面提示后点一下就能升级。

### 卸载 / 恢复官方版

「设置 → 应用 → 已安装的应用」里找 `mathmodel <版本> 开发版` 卸载，你的论文和会话会保留。
想要官方版，直接重新安装官方安装包即可完全还原。
